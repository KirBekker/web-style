# Web Style

Codex skill for planning, reviewing, and implementing website visual style and interface presentation.

## Install

Copy this folder into your Codex skills directory, then invoke it with `$web-style`.

The [source index](references/sources.md) contains dated design-system guidance, standards, platform releases, and research references from 2025–2026. Research papers marked as arXiv preprints are provisional and should not be treated as production requirements.
